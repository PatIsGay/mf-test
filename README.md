# MF-Log Test

Testkanal der Web-App MF-Log mit neutralen Beispieldaten, zum Ausprobieren von Änderungen.

- Testkanal: https://patisgay.github.io/mf-test/
- App: https://patisgay.github.io/mf-log/app/

Eigenes Repo, damit sich der Testkanal auf Android neben der App als zweite App installieren lässt (die Geltungsbereiche dürfen sich nicht überlappen). Die Dateien werden automatisch aus einem privaten Entwicklungs-Repo hierher kopiert; Änderungen bitte nicht direkt hier vornehmen.
